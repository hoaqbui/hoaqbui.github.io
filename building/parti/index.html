Parti

An early-stage multi-agent orchestration system that runs a research, plan, implement, verify, and evaluate loop across a three-node home lab: a Mac Studio, a GB10 workstation, and a NAS.

One task, start to finish

  1. 01You ask. The main agent plans the work and hands it to a coding worker: Claude Code or Codex.

  2. 02A worker needs you: pick between two fixes, or approve a file write.

  3. 03An agent drives the built-in browser. You can watch it, take over or stop it.

  4. 04Review the changes and the diff, then commit.

  5. 05The team learns: it proposes new skills, which you accept, edit or reject.

How it runs

Why build it

One person gets a coherent, capable team of AI collaborators without managing every agent or every conversation.
